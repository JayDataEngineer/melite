# character-factory

The AssetFurnace-shape chain, estate-native. THREE card stages on the
`comfyui` card plane (lift → rig → motion), agent-driven through the
queue door — the registry row (`flowsRegistryRows.ts`
CHARACTER_FACTORY) is the TEMPLATE, this leaf is the agent face.

- **Route B is the chain** (operator ruling 2026-10-09: Route A
  closed, B/C blessed). The lift fills the frame with a clothed
  character; AI never estimates a naked body.
- **Multi-stage serves at validate; start refuses multi-stage.**
  Agents drive one card at a time (`{model:}` door or the bench);
  the done-stage skip makes re-runs cheap (a done lift never
  re-executes).
- **Creature motion is never a registry stage.** The MOTION phase
  (unimate dataset clip → rig `copy` bridge) rides the game-profile
  MCPs — unimate is an MCP, not melite. The leaf skill documents the
  bridge; the registry stays melite cards only.
- **Unity is the EDITOR phase**, not a stage: the animated GLB (or
  the rig `fbx` arm's FBX) imports through the game profile's Unity
  MCP. No Unity seats, servers, or proxy nodes in melite (M12/M15).
