# vfx-sprite — current authoring guidance

Status: **CURRENT authoring guidance**. The loaded image card owns the effect
sprite parameters and delivery expectations.

## Agent loop

```text
melite_discover → melite_load → melite_construct
```

Compose one isolated effect sprite or the declared variation set on the
shared bench. Browser sessions stop at the user's Run press; a sanctioned
headless commission may use `melite_flow` and `run_status`.

## Authoring and review

Describe the effect substance, isolation/background requirements, and seed
strategy only through loaded card parameters. Verify the actual artifact and
its recognition/alpha requirements. Do not invoke a raw gateway, retired YAML
lane, or unverified conversion script.
