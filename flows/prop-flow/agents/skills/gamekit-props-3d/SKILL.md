# gamekit-props-3d — current prop guidance

Status: **CURRENT authoring guidance**. The live prop card/flow declares its
own concept, mesh, remesh, review, and optional rig capabilities.

## Agent loop

```text
melite_discover → melite_load → melite_construct
```

The browser agent composes and the user presses Run. A headless commission may
use `melite_flow` and `run_status` under the runbook. Do not use a raw
endpoint or a historical YAML template.

## Authoring rules

- Match the concept image and declared background/shape contract.
- Use the loaded remesh budget and review-view names.
- Use an optional rig only when the loaded contract exposes it.
- Verify the final mesh and declared views before delivery.

A separate Unity/FBX delivery step is external to this card and requires its
own verification receipt.
