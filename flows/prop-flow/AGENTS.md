# prop-flow — authoring notes

Status: **AUTHORING LEAF — not an executable named flow**. This directory
documents static prop/weapon intent. No row named `prop-flow` is currently
present in the authoritative TypeScript flow registry. Discover the live
cards/flows with `melite_discover`.

## Intended composition

Concept image → mesh generation → declared remesh budget → turntable review.
Budget class and provider come from the loaded card/model declaration, not
from a path in this file.

## Agent contract

compose only and the user presses Run. Headless commissions may execute
through `melite_flow` under the runbook. Do not use the retired file-based
flow syntax, raw estate HTTP, or a hand-built graph.

## Review rules

- Check the declared review views and budget before delivery.
