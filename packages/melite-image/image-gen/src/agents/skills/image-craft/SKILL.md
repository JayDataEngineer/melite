# Image Craft

## Prompt discipline

Lead with the subject, then the action, then the environment, then the
style suffix. Keep style suffixes IDENTICAL across a set — that is what
makes it a set.

## Seed families

- 100-199: hero assets
- 200-299: variants of a hero
- 600-699: UI icons
- 700+: attachments

Same seed + same suffix = same world texture across a family.

## Grid discipline (sheets)

When a sheet is the goal: square canvas, strict grid, N poses, flat
background color named in the prompt, and match background_color in any
downstream 3D brick to it.
