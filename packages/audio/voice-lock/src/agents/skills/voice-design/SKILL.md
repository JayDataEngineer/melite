# Voice Design

## Description seeds

The style instruction IS the voice DNA: age, texture, pace, weight,
edge. "young female, raspy edge, fast clipped delivery" — concrete
beats poetic.

## Reference anchors

A reference clip pins the design to a real timbre; the description
then shapes delivery around it.

## Lock law

Export the .qvoice ONCE, name it after the character (lowercase), and
reuse that exact file for every line the character speaks. A voice is
a file, not a prompt.
