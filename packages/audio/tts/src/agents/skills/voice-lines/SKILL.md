# Voice Lines

## Serial law

One line per call. A dialogue scene is N serial cards — never one card
carrying a whole script.

## Voice DNA

Per character, lock: the .qvoice embedding (or preset voice) AND the
style instruction. Both identical across every line the character
speaks — that is what makes them recognisable.

## Delivery

Write style instructions about DELIVERY (pace, weight, edge), not about
the scene. The text carries the scene.
