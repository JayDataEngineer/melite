# melite-card-view

The studio's card surfaces package: the browser bundle row mounted by
the estate's patch layer. Host half (`src/index.ts`) logs the mount
line; every card surface rides the estate remotes over `/api`.

## Invariant omission

This package ships no `./invariant` companion. The DSH package rules
publish an invariant installer only when independent observations can
diverge at runtime; the card surfaces derive everything they show from
the estate remotes' responses and hold no cross-package claims a
runtime assertion could check. The empty installer that stood here
until 2026-10-18 asserted nothing and was deleted (conformance sweep
F20).
